    Special labels reference
    
    
      
    __metrics_path__
    
      
    Overrides the metrics path of the scrape (must start with /).
    
      
    __scheme__
    
      
    http or https.
    
      
    __scrape_interval__
    
      
    Per-group scrape interval, a Prometheus duration like 30s, 5m, 1h30m.
    
      
    __scrape_timeout__
    
      
    Per-group scrape timeout; must not exceed the interval.
    
      
    __param_<name>
    
      
    Sets the URL query parameter name for the scrape.
    
    
    
    
    Special labels act on the group level: targets needing different metrics_path or scheme belong in separate groups. Unknown __… labels are saved without validation.
